# Request examples

这些示例只展示“用户想得到什么”，不附带任何第三方视频、转写或模拟证据。

## 吸收

```text
请把这个视频整理成一份没看过原视频也能独立理解的知识文档。陌生术语第一次出现时请用中文解释，并保留可以回看原视频的时间证据。
```

## 判断

```text
请判断访谈主角的关键经历是否可信。区分公开资料已经支持、只有本人陈述、合理推断和目前无法验证的部分，不要因为缺少证据就直接判定为虚假。
```

## 应用

```text
请分析这个视频，并把真正适用于我当前项目的观点连接到项目资料。缺少项目基线时先指出缺口，不要虚构客户、数据或精确比例。
```

## 分析后继续交流

```text
视频里作者为什么把这两个概念放在一起？这个推理成立需要哪些前提？
```

同一对话可以直接继续提问；新对话应提供作品链接、作品 ID 或已有分析目录，让 Skill 复用已生成资产。
